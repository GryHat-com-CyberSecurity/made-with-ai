# Made with AI · GRYHAT

A public gallery of AI-generated video work by GRYHAT. Every clip is labeled with the tool, the brand, and the date. Original work only.

- `manifest.json` — the source of truth; add a clip here and run `python3 build.py`.
- `posters/` — one still per clip (in the repo).
- `media/` — the clips themselves, **not** in the repo; they're hosted and referenced by `src` in the manifest.
- `index.html` — generated; served by GitHub Pages.
